# Example MCP session

Generated by `python examples/run_examples.py`: an MCP client started
`server.py` over stdio, listed the tools and called each one.

## Tools offered by the server

| Tool | Parameters | Read-only |
|---|---|---|
| `vcf_stats` | `path` | True |
| `bam_stats` | `path`, `region` | True |
| `bam_qc` | `path`, `region` | True |
| `bam_depth_profile` | `path`, `region`, `min_depth`, `max_points` | True |
| `h5ad_summary` | `path`, `column` | True |
| `h5ad_column_stats` | `path`, `column`, `bins` | True |
| `fastq_stats` | `path`, `max_reads` | True |
| `fastq_quality_profile` | `path`, `max_reads`, `max_points` | True |
